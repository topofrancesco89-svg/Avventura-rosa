AVVENTURA ROSA - progetto Android nativo (WebView)

Questo progetto contiene il prototipo HTML5 dentro un'app Android a schermo intero e in orientamento orizzontale.

Per generare l'APK:
1. Installa Android Studio e Android SDK (API 35) su un PC.
2. Apri questa cartella in Android Studio.
3. Attendi la sincronizzazione Gradle.
4. Seleziona Build > Build Bundle(s) / APK(s) > Build APK(s).
5. L'APK di debug si trova in app/build/outputs/apk/debug/app-debug.apk.

Per una distribuzione pubblica serve creare una chiave e generare un APK/AAB firmato.

Package: it.avventurarosa.game
Versione: 1.0
Minimo Android: 6.0 (API 23)
